# پیش‌نمایش مینی‌اپ

منبع رابط سه نقش (مدیر کانال، مشتری، پشتیبانی) تا صفحهٔ «اتصال لینک‌یار».

این پوشه روی سی‌پنل اجرا نمی‌شود و به جنگو وصل نیست. دادهٔ داخلش دمو است و در مرورگر نگه داشته می‌شود. مینی‌اپ سرور همچنان `miniapp/static` است.

مسیرها مثل پیش‌نمایش‌اند: `@/lib/i18n`، `@/lib/market`، `@/components/market`. متن‌های کاربر فقط در `src/lib/i18n/fa.ts` است.

آمار عضو و بازدید را مدیر وارد نمی‌کند. در این پیش‌نمایش شبیه‌سازی می‌شود. برداشت واقعی سمت سرور است: حساب لینک‌یار (`BALE_TOKEN`) و جدول `ChannelStatSnapshot` بعد از `migrate`.

صفحهٔ صحت اتصال فقط برای پشتیبانی است: خانه، کارت «حساب لینک‌یار». ادمین بودن لینک‌یار برای انتشار است و جدا از خوانده شدن آمار نشان داده می‌شود.

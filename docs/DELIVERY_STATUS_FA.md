# وضعیت تحویل Linkyar v2

این سند نمای کلی نسخهٔ یکپارچه است. ارزیابی جزئی قابلیت‌ها و معیارهای پذیرش در `REQUIREMENTS_AUDIT_FA.md` قرار دارد.

## اصلاحات اضافه‌شده به آخرین نسخه

- مدیریت تعرفهٔ مدیر به API متصل شده است.
- فرم شارژ کیف پول مبلغ انتخابی را به endpoint صدور فاکتور بله می‌فرستد.
- شارژ کیف پول مشتری با مبلغ و پرداخت‌کننده اعتبارسنجی می‌شود، پس از webhook با کلید یکتا ثبت می‌شود و از درآمد قابل برداشت مدیر جداست.
- پیش‌نویس بنر علاوه بر متن، رسانه را روی سرور نگه می‌دارد و پس از بازکردن مجدد قابل بازیابی است.
- تازه‌سازی متادیتای کانال روزانه محدود شده است؛ لینک جدید توسط cooldown لینک قدیمی مسدود نمی‌شود.
- پیام تأیید بنر نام کسب‌وکار و دکمهٔ رفتن به فهرست کسب‌وکارها را در بر می‌گیرد.

## وضعیت تست

بررسی نحوی و تطبیق فایل‌های JavaScript قابل انجام است. تست‌های Django باید روی محیط دارای Django و تنظیمات پروژه اجرا شوند. هیچ ادعایی دربارهٔ پرداخت واقعی بله یا پذیرش نهایی روی سرور زنده در این سند نشده است.

سیاست مالی بنر اول رایگان و هزینهٔ بنرهای بعدی از طریق `BANNER_FEE_TOMAN` قابل تنظیم است. اعتبار قبل از انتشار بررسی می‌شود و خرج کیف پول با قفل کاربر انجام می‌شود.


## بازطراحی رابط کاربری (۲۰۲۶-۱۰-۲۲)

- صفحهٔ بازار با هدر گرادیانی، جست‌وجو و فیلتر واضح و کارت‌های کانال بازطراحی شد.
- صفحه‌های حساب/نقش، بنرها، سفارش‌ها، کیف پول و کسب‌وکارها با اجزای بصری هم‌خانواده به‌روز شدند.
- APIهای موجود و کلیدهای bind/شناسه‌های رویداد برای عملیات اصلی حفظ شده‌اند.
- شرح تغییرات و محدودیت‌های آزمون بصری در `UI_REFRESH_NOTES_FA.md` آمده است.

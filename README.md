# لینک‌بانک — مارکت‌پلیس تبلیغ در بله

بازو و مینی‌اپ روی همان دیتابیس جنگو کار می‌کنند. ورود بازو فقط **لانگ‌پولینگ** است. وب‌هوک آپدیت را پردازش نمی‌کند و `poll_bot` اگر وب‌هوکی مانده باشد آن را پاک می‌کند.

## اجرا روی سی‌پنل

1. Python App با ریشهٔ همین پوشه. Startup file: `passenger_wsgi.py` و callable: `application`. این فرآیند فقط سایت و مینی‌اپ را سرو می‌کند.
2. `pip install -r requirements.txt` و `python manage.py migrate`.
3. در Environment Variables (یا `.env` کنار پروژه):

```
DJANGO_SECRET_KEY=...
DEBUG=0
USE_SQLITE=0
DB_NAME=...
DB_USER=...
DB_PASSWORD=...
DB_HOST=localhost
BALE_BOT_TOKEN=توکن بازوی لینک‌ساز
BALE_PROVIDER_TOKEN=توکن کیف‌پول از @botfather
BALE_TOKEN=سشن حساب لینک‌یار
MINIAPP_BASE_URL=https://دامنه-شما
DEBUG_BALE_ID=شناسه عددی حساب خودتان
OPERATOR_BALE_ID=شناسه اپراتور تسویه
```

4. پولینگ را جدا از وب‌اپ نگه دارید (همان روش فعلی):

```bash
python scripts/poll_bot.py
```

مینی‌اپ: `https://دامنه/miniapp/` — دادهٔ کانال، تعرفه، سبد، بنر، کیف‌پول و روزهای پر از دیتابیس خوانده و نوشته می‌شود.

## چه کسی دیباگ می‌بیند

`DEBUG_BALE_ID` یک یا چند شناسهٔ عددی بله است (با ویرگول). فقط همان حساب:

- دکمهٔ «پرداخت انجام شد (تست)» و دستور `/paid_شماره` را می‌بیند
- در مینی‌اپ می‌تواند بین نقش مدیر و مشتری جابه‌جا شود

بقیه فقط فاکتور واقعی کیف‌پول بله را می‌بینند. سفارش وقتی پرداخت‌شده می‌شود که آپدیت `successful_payment` به پولینگ برسد، و فقط اگر وضعیتش «در انتظار پرداخت» باشد.

## سناریو

1. مدیر کانال را ثبت می‌کند (شناسهٔ عددی‌اش باید در توضیحات کانال باشد)، تعرفه می‌گذارد و در صورت نیاز روزی را پر می‌کند.
2. مشتری بنر را داخل بازو از کانال مرجع فوروارد می‌کند، از مینی‌اپ روز خالی را به سبد اضافه می‌کند و تسویه می‌کند.
3. مدیر هر آیتم را تأیید، رد، یا با زمان تازه پیشنهاد می‌کند. اگر زمان عوض شود، مشتری باید قبول کند.
4. بعد از تأیید، فاکتور کیف‌پول ارسال می‌شود. مبلغ داخل سامانه تومان است و به بله به ریال (×۱۰) می‌رود.
5. سر وقت، حالت کانال تعیین می‌کند تبلیغ با لینک‌ساز برود، با لینک‌یار برود، یا به مدیر یادآوری شود.
6. پس از اجرای تأییدشده، خالص مبلغ پس از کارمزد به کیف مدیر می‌نشیند. بازگشت وجهِ انتشار ناموفق هم در همین کیف ثبت می‌شود.
